# 色の枠

スキルが決めるのは色の値だけで、意味は決めない。どの色に何の意味を当てるかは文書のまとまり(1 つのリポジトリ、1 つの発表)ごとに決め、案件側の対応表に書く。

## 確かめた値

`scripts/check.py` と同じ式(WCAG 2.x の相対輝度)で計算した。

- **文字(4.5:1 以上)**: 本文 13.9、補足 7.0、主 6.5、対の文字用 5.8(いずれも背景 `#f5f6f4` に対して)。淡い塗りの上でも 5.2 以上ある。対の線用の値 `#b35a1f` は文字に使うと 4.4 で足りないので、文字には `#9a4a14` を使う。
- **白い文字**: 主の塗りの上で 7.0、対の塗りの上で 4.8。
- **枠線(3:1 以上)**: 中立 `#7a8490` は、背景に対して 3.5、`#e8eaed` に対して 3.2、箱の塗りに対して 3.7。
- **色覚**: 主と対は青と橙で、Okabe と Ito の配色と同じく色相の対で見分けられる。明るさも違う(背景に対して 6.5 と 4.4)ため、白黒にしても区別が残る。赤と緑の組み合わせは使わない。

## 案件側の対応表

案件のリポジトリに `docs/diagram-legend.md` などの名前で、次の形の表を置く。名前と場所は案件の慣例に合わせる。

| 記号 | 意味 |
|---|---|
| 主の色 | 許可する・守る側 |
| 対の色 | 許可しない・課題 |
| 中立の塗り | PC の外にあるもの |
| 破線 | 組織の設定で変わる |
| 太い主の枠 | OS が強制する境界 |

対応表が無いときは、図を描く前に作るか、ブリーフで割り当てを決めて報告する。
